EVE PI Load Calculator

How to run:
1. Extract the entire ZIP.
2. Open the extracted folder.
3. Double-click "EVE PI Load Calculator.exe".

No Java installation is required.

This is a portable application.
Keep the entire folder together.
Do not move only the EXE by itself.

Notes:
- Do not launch the EXE from inside the ZIP preview of your
  archive tool; extract first.
- The application is currently unsigned, so Windows may show a
  SmartScreen warning. Choose "More info" -> "Run anyway" if you
  trust the source. This does not require disabling any system
  security feature.
